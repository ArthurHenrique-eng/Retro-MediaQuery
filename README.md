# Retro-MidiaQuery
O site tem como objetivo apresentar o catálogo de discos disponíveis de forma organizada, visual e intuitiva, permitindo que os visitantes conheçam diferentes gêneros musicais, como Rock, Pop Rock, Jazz, Música Clássica, MPB, Sertanejo, Sertanejo Universitário, entre outros, incluindo produções das décadas de 1980, 1990 e 2000.
